# Privacy

LOOTBOX proves that a prize reached its winner without ever publishing who or where the winner is.

## What happens to each piece of data

| Data | Who handles it | Kept by LOOTBOX | Published |
|---|---|---|---|
| Winning wallet | Everyone, since it's on Solana | Yes | Yes |
| Name, address, phone | The checkout (Shopify), the order service (Zinc), the retailer and the carrier: only what's needed to ship | **Privately, until the drop is complete.** Then it's deleted | **Never.** Only a salted fingerprint |
| Email | The checkout, for order updates | **No** | **Never** |
| Tracking numbers | The order service (Zinc) and the carrier | **No** | **Never** |
| Products, prices, order number | Everyone | Yes | Yes. This is what proves the purchase |

The shipping address comes from the checkout and is kept in a private table that only LOOTBOX's server can read. Neither the website's visitors nor its public database key can see it. It's used for two things: placing the order, and checking that no proof leaks it. When the drop is complete (the winner confirms the prize arrived, or 14 days after delivery), it's deleted.

Shopify and Zinc keep their own records of the order, like any store or order service.

## The address fingerprint

When a winner claims, LOOTBOX publishes a fingerprint of their address that nobody can reverse. Only the winner can check it.

1. The address is tidied into one line: uppercase, punctuation removed, a 5-digit ZIP. For example:

<CodeBlock>{normalized}</CodeBlock>

2. A random 32-byte secret is generated and given to the winner. LOOTBOX's copy is deleted along with the address when the drop is complete.
3. The published fingerprint is `SHA-256("LOOTBOX-ADDR-v1|" + address + "|" + secret)`.

Without the secret, guessing addresses doesn't help, because each guess would also need the 32-byte secret. With it, the winner can type their address into the proof page and confirm it matches. That check runs only in their browser and nothing is sent anywhere.

## Leak guard

Before any proof is published, an automatic check searches everything about to be revealed for the winner's name, street, city, ZIP and phone, ignoring case, spacing and punctuation. If anything matches, publishing stops. A blocked proof is better than a leaked address.

## In the code

`lib/proofs/commitment.ts` (fingerprint) and `lib/proofs/pii-guard.ts` (leak guard) are built and tested, including leaks written in different formats. The address is deleted by the drop engine's last step, in `lib/engine/live.ts`.
