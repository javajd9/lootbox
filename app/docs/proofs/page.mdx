# The 8 proofs

Every drop moves through eight steps. Each step is backed by evidence that comes from the source, not from LOOTBOX.

| Step | Proven by | Public | Hidden |
|---|---|---|---|
| **1. Funded** | Fee transactions into the treasury on Solana | Amounts, transactions | Nothing |
| **2. Paid** | The moment the pool fills: one Solana transaction that swaps the goal's worth to USDC, sends it from the treasury to the purchasing account, and carries the drop's fingerprint | Amount, transaction | Nothing |
| **3. Drawn** | Every snapshot's fingerprint and the ticket list's fingerprint on Solana, plus the ORAO VRF result | Snapshots, ticket list, randomness, winning ticket | Nothing |
| **4. Claimed** | The address fingerprint, posted on Solana once the winning wallet has signed and finished the checkout | The fingerprint | The address |
| **5. Ordered** | A zkTLS proof of the order service's own response | Products, price cap, total, retailer order number, status | Name, address, phone, API keys |
| **6. Shipped** | A zkTLS proof of the order service's tracking record | Carrier, "shipped", time | Tracking number, locations |
| **7. Delivered** | Same as above, once every package has arrived | "Delivered", time | Tracking number, locations, who signed |
| **8. Received** | A message signed by the winning wallet | The message, the signature | Nothing private |

## zkTLS, in one paragraph

When a server sends data over HTTPS, the connection is encrypted and authenticated, but normally only you can see that it happened. **zkTLS** (LOOTBOX uses Reclaim Protocol's zkFetch) adds an independent witness to the connection and produces a proof that this exact response came from that server. Selected parts can be blacked out without breaking the proof. So instead of a screenshot of an order, you get the order service's real response with the address removed, and anyone can verify it wasn't edited.

## Fingerprints and the chain

Every fingerprint LOOTBOX posts is a Solana memo in one format, `LOOTBOX|v1|<drop>|<step>|<values>`, signed by the proof publisher on [Addresses](/docs/addresses).

**Steps 1 to 4 happen on Solana**, so their evidence is the transaction itself. Paid, Drawn and Claimed each carry their fingerprint in that transaction.

**Steps 5 to 8 come from outside Solana**, so each one's evidence is wrapped in a **proof package**, and every package includes the fingerprint of the one before it:

- **Editing a package changes its fingerprint**, which breaks the link from the next one.
- **Removing or reordering packages breaks the chain.**
- **Each package's fingerprint is posted on Solana when it's published**, so even the newest package can't be changed later.
